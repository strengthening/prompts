请使用 Three.js 制作一个精美、细节丰富、可以交互的体素风格日式庭院，将全部 HTML、CSS 和 JavaScript 放在一个 HTML 文件中。

场景要求：
- 在悬浮的小岛上建造一座多层日式宝塔，表现出屋檐、立柱、台阶和窗户的细节。
- 庭院包含粉色樱花树、竹林、石板小路、石灯笼、池塘，以及跨越池塘的木拱桥。
- 池塘中有游动的锦鲤，空中有缓慢飘落的樱花花瓣。
- 所有场景物体采用立方体组成的体素风格，色彩协调，构图有层次。
- 实现平滑的昼夜变化，夜晚点亮灯笼，并出现萤火虫。
- 支持鼠标旋转、缩放和平移视角，初始视角可以看到整个庭院。
- 提供简洁的控制面板，可以调整时间、花瓣数量和风速，并开关自动旋转、阴影和动画。
- 尽量使用实例化渲染等方式减少开销，保持动画流畅。
所有模型通过代码生成，不使用外部图片或模型文件。Three.js 和配套控件可以从 CDN 加载，但必须使用相同版本，并正确处理模块依赖。无需构建工具。

请直接输出完整、可运行的 HTML 代码，不要省略任何实现，不要只给示例骨架。
